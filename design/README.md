## 设计 Token

```
主色     #0A1B33 深海军（头图、主标题）  #1F6FEB 主蓝（操作、强调）  #E9F0FE 浅蓝（图标底）
背景     #F4F7FC 页面底  #FFFFFF 卡片  #E4EAF3 分割线
状态     出勤 #0FA968 · 迟到 #F5A524 · 缺席 #E5484D · 伤停 #E8590C
圆角     卡片 16px · 按钮 13px · 标签 6px
字号     22 大标题 / 17 卡片标题 / 14 正文 / 12 辅助 / 10 标签
```

主色只用于**可操作的按钮、进度、强调数字**，不铺大面积背景；深蓝只出现在顶部头图，
形成「上半深、下半浅」的固定节奏，所有页面一致。

## 重新渲染

Chrome 在本机沙箱里起不来（需要命名管道 IPC），要放宽权限执行：

```powershell
# 1. 渲染整张画板（2 倍图）
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=old --no-sandbox `
  --disable-gpu --hide-scrollbars --force-device-scale-factor=2 --window-size=1285,2780 `
  --screenshot="D:\project_hyt\strikers-miniprogram\design\out\board.png" `
  "file:///D:/project_hyt/strikers-miniprogram/design/mockups.html"

# 2. 切成单屏
python design\crop.py
```

画板尺寸按 3 列 × 3 行、手机 375×812、列距 32、行距 40（含 36px 说明文字）、页边距 48、
顶部标题区 144 计算得出。改网格参数时要同步改 `crop.py` 里的坐标。

## 落地建议

- 颜色直接照搬成小程序 `app.wxss` 里的 CSS 变量，不要在设计稿和代码里各写一套。
- 头像用「姓氏首字 + 蓝系渐变底」的占位方案，等真实头像上传后再替换，避免上线前没有图。
- 状态色的**色块 + 文字**要成对出现（不能只靠颜色区分出勤/迟到/缺席），色弱队友也能看懂。
- 点名台的三态按钮是单人最高频操作，按钮尺寸 30×30 是下限，真机上不要再压缩。
