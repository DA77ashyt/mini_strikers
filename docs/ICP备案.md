# 小程序 ICP 备案 · 操作手册（个人主体）

> 依据：微信官方《小程序备案操作指南》《备案类目选择》《备案材料与真实性核验》《工信部短信核验》等文档（2023-09 起执行）。
> 本文只记录**本队这个小程序要做的事**，不复制官方全文；具体以小程序后台当期提示为准。

## 一句话结论

个人主体备案**不难但卡时间**：平台初审 1–2 个工作日，工信部短信核验**只有 24 小时**，通管局 1–20 个工作日。
所以**越早提交越好**，不要等开发做完再备案——审核期正好用来写代码。

## 现在就能做的三件事（不依赖任何人）

1. 用管理员微信登录 **微信公众平台 → 小程序后台**，首页看有没有「去备案」入口（或 设置 → 小程序备案）。
   - 未上架的新小程序自 2023-09-04 起就有入口；看不到说明主体或小程序信息没完善。
2. 准备 **主体负责人（就是你）** 的手机号，必须是本人实名、能收短信。
3. 确认小程序**名称与简介**里不要出现「社区」「论坛」「交友」「UGC」这类词——个人主体最容易在这被卡。

## 材料清单（个人主体）

| 材料 | 说明 |
| --- | --- |
| 个人有效身份证件 | 正反面照片，四角完整、不反光 |
| 手机号 | 与身份证本人一致，用于工信部短信核验 |
| 人脸核身 | 平台内完成：白色/浅色背景、不戴帽子耳机口罩、不裸露上半身 |
| 《互联网信息服务承诺书》 | 平台内阅读并确认，无需线下打印 |
| 《小程序备案真实性核验单》 | 平台自动生成，无需自己准备 |

**不需要**：授权书（个人主体负责人=小程序负责人，默认同一人）、前置审批文件（新闻/出版/药品医疗器械/网约车/文化/宗教等类目才要，我们不涉及）。

## 五步流程与时间

1. **填写备案信息**（主体、负责人、小程序信息、服务内容）——当天可完成
2. **平台初审**——1–2 个工作日，可能电话回访，注意接听
3. **工信部短信核验**——12381 发到负责人手机，**24 小时内**到 <https://beian.miit.gov.cn/> 完成核验，**逾期自动驳回，要重新走**
4. **通管局审核**——1–20 个工作日
5. **下发备案号**——上线后自动展示在「更多资料页」，不需要自己悬挂

> 提醒：第 3 步最容易翻车。提交后那两天把手机放身边，短信来了立刻去核验。

## 服务内容怎么选（个人主体）

官方允许个人备案选择的「服务内容」里，和我们相关的有：

- **工具 → 信息查询**（推荐）：队史资料、照片、编年史的浏览，属于信息展示。
- **体育 → 体育场馆服务**：可作补充，但主体是个人，说明里不要写成"提供场馆预订"。
- **不要选**：网络社交（社区/论坛/笔记）、信息发布类。个人主体做 UGC 几乎必被要求补充材料或直接驳回。

### 这个选择对产品的约束

| 产品设计 | 备案口径下的处理 |
| --- | --- |
| 「上传一段记忆」 | 定位为**投稿**，必须有编辑审核后才入库；不做公开评论区、不做用户互相关注 |
| 队员个人页 | 只展示队内已有资料，不提供用户自行编辑的公开主页 |
| 分享 | 分享的是页面，不是"发帖" |

代码层面对应：`pages/submit` 只做本地收集 + 提示「由队史编辑整理入馆」，不直接写入任何对外可见列表。

## 常见驳回原因（按发生概率排序）

1. 短信核验超时（24 小时）——最高频。
2. 小程序名称/简介含禁词（社区、论坛、直播、交友、投资、医疗）。
3. 身份证照片模糊、反光、边角缺失。
4. 人脸核身环境不合格（背景杂色、逆光、戴耳机）。
5. 服务内容与实际功能不符（选了"工具"却明显是社交产品）。
6. 主体信息与微信支付/认证信息不一致。

## 提交后要留的档

- 备案号（形如 `粤ICP备xxxxxxxx号-1X`）
- 提交时间与每步通过时间（后面排查「为什么还没下号」要用）
- 平台初审/通管局的回访电话记录

## 与小程序的对应关系

- `project.config.json` 里的 `appid` 现在是 `touristappid`（游客模式，**不能备案**）。拿到正式 AppID 后只改这一处即可。
- 备案通过前可以先发**体验版**（不需要备案），给队员试用；**正式发布必须先有备案号**。
- 云开发环境与备案无关，可以先开通。
